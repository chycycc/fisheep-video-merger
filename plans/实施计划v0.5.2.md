# Fisheep 视频工具箱 v0.5.2 实施计划

> 深度重构与逻辑优化：消除重复代码、提取常量、清理死代码、统一模式

## 背景

v0.5.1 功能完成（13/15），代码分析发现大量重复、魔法数字、死代码、耦合问题。v0.5.2 专注代码质量。

## 优先级一：消除重复代码（最大收益）

### 1. 合并 FFmpeg 执行器
- `merger.py` 的 `_run_ffmpeg_with_progress`（148行）与 `ffmpeg_runner.run_ffmpeg` 几乎完全重复
- 给 `ffmpeg_runner.run_ffmpeg` 添加 `process_callback` 参数
- 删除 `merger.py` 的重复实现，改用 `ffmpeg_runner.run_ffmpeg`

### 2. 统一 `get_ffmpeg_path`
- 三处实现：merger.py（无缓存）、ffmpeg_runner.py（模块缓存）、ffprobe.py（双检锁）
- merger.py 改用 `ffmpeg_runner.get_ffmpeg_path()`

### 3. 提取 bridge.py 重复模式
- `_format_file_info(filepath)` 辅助函数（文件大小/修改时间格式化）
- `_run_tool_operation()` 通用工具操作封装

## 优先级二：清理死代码

### 4. 移除未使用导入
- bridge.py: `remux_single`, `ConflictStrategy`, `generate_output_path`

### 5. 移除空函数
- app.js: `initDashboardToggle`, `renderQueue`, `renderPending`, `renderMuxed`, `initConfigPanelToggle`

### 6. 移除未使用变量
- merger.py: `last_pct`

## 优先级三：统一模式

### 7. 定义常量
- ffmpeg_runner.py: `PROGRESS_THROTTLE_SECONDS`, `MAX_DISPLAY_PERCENT`, `FFMPEG_WAIT_TIMEOUT`, `FFMPEG_KILL_TIMEOUT`, `STDERR_CHUNK_SIZE`, `MAX_ERROR_LENGTH`
- bridge.py: `MAX_DISPLAYED_LOGS`

### 8. 统一 import subprocess
- bridge.py 顶层导入，删除局部导入

### 9. 修复 CSS 语法错误
- style.css: 移除孤立的 `}`

### 10. 统一错误响应格式
- 所有 API 返回 `{"status": "...", "message": "..."}`

## 估算

约 2-3 小时
