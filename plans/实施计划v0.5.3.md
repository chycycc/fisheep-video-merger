# Fisheep 视频工具箱 v0.5.3 实施计划

> 视频预览 + 自动命名 + 多平台支持 + 全面代码质量修复
> 日期：2026-05-28
> 状态：✅ 已完成

## 背景

v0.5.2 完成代码质量重构后，v0.5.3 实现原 v0.6.0 设计文档中的核心功能（视频预览、自动命名、多平台支持），并通过 simplify review 发现并修复了 25 项 bug/性能/死代码问题。

## 功能一：视频侧栏预览

### 已完成
- `ffprobe.py`：新增 `extract_screenshot()`（FFmpeg 截取第一帧）+ `get_video_detail()`（分辨率/编码/码率/时长/帧率）+ `_probe_file()` 共享函数
- `bridge.py`：新增 `get_video_preview()` API，返回截图 base64 + 元数据，并行执行 ffprobe + ffmpeg
- `app.js`：单击队列行时 200ms 防抖加载预览，请求计数器防竞态
- `index.html`：配置面板新增预览区域（16:9 截图 + 6 项信息）
- `style.css`：预览面板样式

### 未完成（移至 v0.5.4）
- 集数信息显示（从 entry.json 提取）
- 来源平台自动检测（B站/YouTube/通用）
- 预览面板显示"来源: B站"

## 功能二：自动命名

### 已完成
- `matcher.py`：新增 `read_bilibili_meta()` 读取 entry.json + `suggest_output_name()` 三级命名策略
  1. B站元数据（系列名 + 集数）
  2. 父目录名 + 文件集数
  3. 兜底：normalize_episode_name
- 所有配对策略统一使用 `suggest_output_name`

### 未完成（移至 v0.5.4）
- 命名模板系统 `{series}_{ep}` + 设置页自定义
- 批量重命名（选中多个文件统一前缀/后缀）
- 合并队列表格"输出名"列显示

## 功能三：多平台支持

### 已完成
- `scanner.py` 已支持全部格式（.m4s/.webm/.mp4/.ts/.flv/.f4v/.m4a/.aac/.mp3/.flac/.wav/.ogg）
- 文件对话框已包含全部格式过滤器

### 未完成（移至 v0.5.4）
- 设置页格式配置 UI（启用/禁用特定格式）
- 平台自动检测（从目录结构推断来源）

## 功能四：非合并工具进度条 ✅

- bridge.py：4 个工具 progress_callback 扩展为接收 pct 参数
- app.js：updateToolProgress 收到 pct 时渲染进度条
- style.css：新增 tool-progress-bar 样式

## 功能五：非合并工具重名冲突 ✅

- bridge.py：新增 `_resolve_output_conflict()` 自动重命名
- 4 个工具 API 调用前均检查冲突

## v0.5.1 遗留修复 ✅

- renderMuxed is not defined（移除无效调用）
- 右键菜单改为原生 + user-select: auto
- 音频提取自定义输出文件名
- AAC 提取时长异常（ADTS→M4A 转封装）
