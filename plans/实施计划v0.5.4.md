# Fisheep 视频工具箱 v0.5.4 实施计划

> 补完 v0.6.0 遗留 + 历史计划未做项 + 新功能
> 日期：2026-05-28
> 状态：📋 待执行

## 背景

v0.5.3 完成了 v0.6.0 设计文档的核心功能，但有 7 个子功能未做完。加上历史计划中标记为"不做"/"暂停"/"未完成"的项目，以及新提出的功能建议，汇总为 v0.5.4。

---

## 一、v0.6.0 遗留（7 项）

### 1. 预览面板：集数信息显示
- **来源**：v0.6.0 功能一
- **改动**：`bridge.py` get_video_preview 返回 episode 字段，`index.html` 预览面板显示"集数: 第3集"
- **依赖**：`read_bilibili_meta()` 已实现

### 2. 预览面板：来源平台自动检测
- **来源**：v0.6.0 功能一/三
- **改动**：`ffprobe.py` 新增 `detect_platform(filepath)` 函数，从目录结构推断（B站有 entry.json，YouTube 有特定目录结构），预览面板显示"来源: B站/YouTube/通用"

### 3. 命名模板系统
- **来源**：v0.6.0 功能二
- **改动**：
  - `matcher.py` 新增 `apply_naming_template(template, variables)` 函数
  - 支持变量：`{series}`、`{ep}`、`{date}`、`{original}`、`{index}`
  - 默认模板：`{series}_{ep}`
  - `bridge.py` 新增 `apply_naming_template()` API
  - `index.html` 设置页新增模板输入框
  - `app.js` 模板变量解析

### 4. 批量重命名
- **来源**：v0.6.0 功能二
- **改动**：
  - `bridge.py` 新增 `batch_rename(indexes, prefix, suffix, replace_from, replace_to)` API
  - `app.js` 批量操作栏新增"批量重命名"按钮
  - `index.html` 重命名对话框（前缀/后缀/替换）

### 5. 设置页格式配置 UI
- **来源**：v0.6.0 功能三
- **改动**：
  - `index.html` 设置页新增"支持格式"区域，checkbox 列表启用/禁用格式
  - `bridge.py` 新增 `update_format_config()` API，持久化到 workspace_state
  - `scanner.py` 读取配置动态过滤

### 6. 平台自动检测（设置页展示）
- **来源**：v0.6.0 功能三
- **改动**：依赖 #2，设置页显示当前已导入文件的平台统计

### 7. 合并队列"输出名"列
- **来源**：v0.6.0 功能二
- **改动**：`index.html` 队列表格增加"输出名"列，显示 suggest_output_name 结果，双击可编辑

## 二、历史计划未做项（4 项）

### 8. 路径镜像与层级控制
- **来源**：优化计划 M-1（⏸️ 暂缓）
- **说明**：保留相对路径 + 可配置裁剪深度，替代当前扁平输出
- **改动**：
  - `path_utils.py` 实现路径镜像算法
  - `bridge.py` settings 新增 `path_depth` 配置
  - `index.html` 设置页新增路径层级控件
- **复杂度**：中

### 9. 导出/导入配对配置
- **来源**：优化计划 D-2（⬜ 未做）
- **说明**：导出当前队列配对为 JSON，跨机器导入复用
- **改动**：
  - `bridge.py` 新增 `export_config()` / `import_config()` API
  - `app.js` 设置页新增"导出配置"/"导入配置"按钮
- **复杂度**：低

### 10. 输出目录模板
- **来源**：新建议
- **说明**：按系列名自动创建子目录（如 `输出目录/视频标题/视频标题_01.mp4`）
- **改动**：
  - `bridge.py` settings 新增 `output_dir_template` 配置
  - `matcher.py` suggest_output_name 返回系列名供目录创建
  - `merger.py` / 工具 API 自动创建子目录
- **复杂度**：低

### 11. 拖拽排序
- **来源**：新建议
- **说明**：合并队列支持拖拽调整合并顺序
- **改动**：
  - `app.js` 实现 HTML5 Drag & Drop 排序
  - `bridge.py` 新增 `reorder_tasks(from_idx, to_idx)` API
  - `index.html` 队列行添加 draggable 属性
- **复杂度**：中

### 12. 去 B站化 — 多平台通用化
- **来源**：新建议
- **说明**：当前 UI 文案、提示语、注释大量硬编码"B站/m4s"，需改为通用表述，支持 B站/YouTube/通用视频
- **改动**：
  - `index.html`：
    - "拖入B站缓存文件夹" → "拖入视频缓存文件夹"
    - "导入 .m4s 单文件" → "导入音视频文件"
    - "B站手机/电脑版缓存目录" → "视频缓存目录"
    - 空状态提示通用化
  - `app.js`：
    - 右键菜单 "导入 B站 缓存文件夹" → "导入文件夹"
    - "导入 .m4s 单文件" → "导入音视频文件"
  - `bridge.py`：注释更新，文件对话框描述通用化
  - `ffprobe.py`：注释 "m4s 文件" → "音视频文件"
  - `matcher.py`：`read_bilibili_meta` 保留但注释明确为"可选增强"
  - `main_web.py`：注释更新
  - `CLAUDE.md`：项目描述更新
- **复杂度**：低（主要是文案替换）

## 三、明确不做（保持原决定）

| 项目 | 原因 |
|------|------|
| 多音轨/字幕支持 | 复杂度高，用户需求低 |
| 硬件加速（GPU） | GPU 检测复杂，兼容性问题多 |
| 国际化 | 目标用户明确为中文用户 |
| CLI 模式 | 桌面工具定位明确 |
