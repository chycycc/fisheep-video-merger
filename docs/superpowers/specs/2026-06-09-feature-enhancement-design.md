# 功能增强设计文档

> 日期：2026-06-09
> 版本：v0.8.0+
> 状态：待审阅

## 背景

现有 5 个工具标签页（格式转换、提取音频、视频压缩、视频裁剪、音视频合并）功能覆盖面广，但部分工具的参数选择较少，无法满足进阶用户需求。本次增强旨在补充常用格式和参数，提升工具灵活性。

## 增强范围

### 1. 格式转换

**现状**：4 种目标格式（MP4/MKV/WebM/AVI），3 种转换模式（流复制/H.264/HEVC）

**增强内容**：

| 项目 | 变更 |
|------|------|
| 目标格式 | 新增 MOV、FLV、TS |
| 转换模式 | 新增 AV1（libaom-av1/libsvtav1）、VP9（libvpx-vp9） |

**实现要点**：
- 后端 `converter.py`：扩展编码器映射，AV1 优先使用 SVT-AV1（速度优于 libaom）
- 前端 `index.html`：在 `#convert-format` 和转换模式下拉框中添加新选项
- AV1 编码较慢，需在 UI 上提示用户

---

### 2. 提取音频

**现状**：4 种格式（MP3/AAC/FLAC/WAV），支持码率/声道/采样率/音量/CBR-VBR/响度标准化

**增强内容**：

| 项目 | 变更 |
|------|------|
| 音频格式 | 新增 OPUS、OGG、M4A、WMA |

**实现要点**：
- 后端 `extractor.py`：
  - 扩展 `_FORMAT_CODEC` 映射：`opus→libopus`、`ogg→libvorbis`、`m4a→aac`、`wma→wmav2`
  - 扩展 `_BITRATE_FORMATS`：加入 `opus`、`ogg`
  - 扩展 `_STREAM_COPY_COMPAT`：加入新格式的兼容映射
- 前端：在提取音频格式选择器中添加新选项
- M4A 本质是 AAC 封装，与现有 AAC 逻辑复用

---

### 3. 视频压缩

**现状**：3 档预设（快速/均衡/高质量），4 档分辨率（原始/1080p/720p/480p），支持目标大小 Two-Pass，音频写死 AAC 128k

**增强内容**：

| 项目 | 变更 |
|------|------|
| 自定义 CRF | 新增滑块/输入框，覆盖预设值 |
| 分辨率 | 新增 4K（3840:-2）、360p（640:-2） |
| 目标码率 | 新增按码率 Two-Pass（除目标大小外的第二种精准模式） |
| 音频编码 | 新增选择（AAC/MP3/AC3/FLAC） |
| 音频码率 | 新增自定义（64k-320k） |

**实现要点**：
- 后端 `compressor.py`：
  - `_PRESETS` 改为默认值，CRF 参数优先使用用户输入
  - `_RESOLUTION_SCALE` 扩展 4K 和 360p
  - 新增 `target_bitrate` 参数，与 `target_size_mb` 二选一
  - 音频参数从写死改为可配置
- 前端：压缩工具选项区新增对应控件

---

### 4. 视频裁剪

**现状**：支持起止时间输入，极速（关键帧流复制）/ 精准（逐帧重编码）两种模式

**增强内容**：

| 项目 | 变更 |
|------|------|
| 裁剪预览 | 输入起止时间后显示对应帧截图 |
| 保留/去除音频 | 新增勾选框（默认保留，可选去除音频或去除视频） |
| 输出格式 | 新增下拉框（默认跟源文件，可选 MP4/MKV/TS 等） |

**实现要点**：
- 后端 `trimmer.py`：
  - 新增 `keep_audio` 参数，为 False 时添加 `-an`
  - 新增 `output_format` 参数，覆盖输出后缀
  - 预览功能复用 `ffprobe.py` 的 `extract_screenshot`，传入指定时间点
- 前端：
  - 起止时间输入框旁加"预览"按钮，调用 Python 获取截图
  - 新增音频保留选项和输出格式下拉框
- 预览截图通过 `evaluate_js` 回传 base64 显示

---

### 5. 音视频合并（设置页）

**现状**：输出格式（MP4/MKV）、并发数（1-8），重编码写死 AAC 192k

**增强内容**：

| 项目 | 变更 |
|------|------|
| 重编码音频选择 | 新增下拉框（AAC/MP3/AC3/FLAC） |
| 音频码率 | 新增输入框（默认 192k） |
| 多音轨合并 | 新增支持一个视频 + 多个音频文件合并为多音轨 |

**实现要点**：
- 后端 `merger.py`：
  - `build_ffmpeg_command` 新增 `audio_codec` 和 `audio_bitrate` 参数
  - 多音轨：多个音频文件时，每个 `-i` 一个文件，`-map` 映射所有音频流
  - 命令示例：`ffmpeg -i video.mp4 -i audio1.m4a -i audio2.m4a -map 0:v -map 1:a -map 2:a -c copy output.mkv`
- 前端（设置页）：
  - 合并配置区新增音频编码和码率选项
  - 多音轨需在合并任务创建时支持选择多个音频文件
- UI 交互：多音轨选择需要在文件配对阶段支持，可能需要调整 matcher 逻辑

## 备注（未来新标签页）

以下功能不纳入本次增强，记录为后续迭代：

- **音频转换**：独立标签页，音频文件之间互转（MP3→AAC、WAV→FLAC 等）
- **音频裁剪**：独立标签页，直接裁剪音频文件（不需要视频源）

---

## 实现优先级

| 优先级 | 功能 | 原因 |
|--------|------|------|
| P0 | 格式转换加格式/编码器 | 用户反馈，最直接 |
| P0 | 提取音频加格式 | 简单参数化 |
| P1 | 视频压缩加参数 | 简单参数化 |
| P1 | 视频裁剪加预览/音频/格式 | 中等复杂度 |
| P2 | 音视频合并加多音轨 | 需调整配对逻辑 |

---

## 技术约束

- 所有新增编码器依赖 FFmpeg 编译时支持（AV1 需 libsvtav1/libaom-av1，VP9 需 libvpx-vp9）
- AV1 编码速度较慢，需在 UI 提示用户预期时间
- 多音轨合并输出容器需支持多音频流（MKV 优先，MP4 有限制）
- 代码注释必须使用中文
