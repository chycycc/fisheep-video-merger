# v0.6.0 设计文档：视频预览 + 自动命名 + 多平台支持

> 日期：2026-05-24
> 状态：已批准

## 背景

用户日常处理多来源视频文件，最大痛点是"识别困难"——下载的文件不知道是哪个视频，只能靠文件名猜。v0.6.0 通过三个功能解决这个问题。

## 功能一：视频侧栏预览

### 架构

- 新增 `ffmpeg_screenshot()` 函数：用 FFmpeg 从视频中截取第一帧，保存为临时 PNG
- 新增 Bridge API `get_video_preview(path)`：返回截图路径 + 详细信息 + 集数信息
- 前端侧栏：选中文件时调用 API，显示截图 + 信息卡片

### 数据流

```
用户选中文件 → JS调用 get_video_preview(path)
  → Python: ffprobe 获取元数据 + FFmpeg 截图
  → 返回 {screenshot_base64, resolution, codec, bitrate, duration, episode}
  → JS: 侧栏显示截图 + 信息
```

### 侧栏布局

```
┌─────────────────────┐
│  [视频截图]          │
│                     │
│  分辨率: 1920x1080   │
│  编码: H.264         │
│  码率: 5000 kbps     │
│  时长: 23:45         │
│  集数: 第3集         │
│  来源: B站           │
└─────────────────────┘
```

### 改动文件

- `ffprobe.py`：新增 `extract_screenshot()` 函数
- `bridge.py`：新增 `get_video_preview()` API
- `app.js`：选中文件时调用 API，更新侧栏
- `index.html`：侧栏预览面板 HTML
- `style.css`：预览面板样式

## 功能二：自动命名

### 架构

- 新增 `auto_rename_tasks(tasks)` 函数：分析目录结构，生成输出文件名
- 命名规则优先级：
  1. B站缓存目录：从 `entry.json` 或目录名提取 AV/SS 号 + 集数
  2. 通用目录：从父目录名提取系列名，从文件名提取集数
  3. 兜底：使用原始文件名

### 命名模板系统

- 支持变量：`{series}`（系列名）、`{ep}`（集数）、`{date}`（日期）、`{original}`（原文件名）、`{index}`（序号）
- 默认模板：`{series}_{ep}`
- 用户可在设置页自定义模板

### 合并前预览命名

- 合并队列表格增加"输出名"列，显示自动命名结果
- 用户可以双击修改输出名
- 支持批量重命名（选中多个文件，统一加前缀/后缀）

### 命名示例

| 目录结构 | 输出名 |
|----------|--------|
| `视频标题/80/xxx.m4s` | `视频标题_01.mp4` |
| `Series/EP03/xxx.m4s` | `Series_03.mp4` |
| `folder/video.m4s` | `video.mp4` |

### 改动文件

- `matcher.py`：提取系列名、集数等变量，`MatchResult` 增加 `suggested_name` 字段
- `bridge.py`：新增 `apply_naming_template()` 函数
- `app.js`：双击编辑输出名，模板变量解析
- `index.html`：队列表格增加"输出名"列，设置页命名模板输入框
- `style.css`：输出名列样式

## 功能三：多平台支持

### 架构

- 扩展 `scanner.py` 的文件扫描模式，从只扫 `*.m4s` 扩展为支持多种格式
- 新增格式配置表，用户可以在设置中启用/禁用特定格式

### 支持格式

| 类型 | 格式 | 来源平台 |
|------|------|----------|
| 视频 | `.m4s` | B站 |
| 视频 | `.webm` | YouTube |
| 视频 | `.mp4` | 通用 |
| 视频 | `.ts` | 直播录制 |
| 音频 | `.m4a` | Apple/YouTube |
| 音频 | `.aac` | 通用 |
| 音频 | `.mp3` | 通用 |
| 音频 | `.flac` | 无损 |

### 自动检测平台

- 从目录结构推断来源平台（如 B站有 `entry.json`，YouTube 有特定目录结构）
- 在预览面板显示"来源: B站/YouTube/通用"

### 改动文件

- `scanner.py`：扩展 `SUPPORTED_VIDEO_EXTENSIONS` 和 `SUPPORTED_AUDIO_EXTENSIONS`
- `bridge.py`：文件选择对话框过滤器扩展
- `app.js`：工具面板文件选择过滤器同步
- `index.html`：设置页增加格式配置

## 功能四：非合并工具进度条（从 v0.5.1 延续）

- 转换/提取/压缩/裁剪增加百分比进度条
- 解析 FFmpeg 输出的 `time=xxx` 为百分比
- 用进度条替代纯文字显示

## 功能五：非合并工具重名冲突（从 v0.5.1 延续）

- 转换/提取/压缩/裁剪复用 merger.py 的 ConflictStrategy 逻辑
- 写入前检查文件存在，触发冲突信号
